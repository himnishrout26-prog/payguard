Model: gradient-boosted trees, Platt-scaled, threshold chosen to minimize ₹(missed fraud) + ₹(false-positive friction cost). Exported from the trained model and run directly in your browser — no server round-trip. Sender history (used for the velocity feature) is kept in memory for this session only and resets on reload. Trained on a synthetic PaySim-schema dataset; see the project README for details.
